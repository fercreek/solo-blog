# brand-kit

`brand.json` es la fuente única de la marca fercontreras.com (colores, tipografía, reglas, OG).
El resto (`src/styles/systemTokens.js`, `soloLevelingTheme.js`, `DESIGN.md`, `scripts/gen-og.py`) debe
leerlo o mantenerse igual a él. Si cambia un valor, cámbialo aquí primero.

Huecos y contradicciones conocidas: campo `pending`.
